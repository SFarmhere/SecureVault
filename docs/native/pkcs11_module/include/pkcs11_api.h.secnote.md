# 📁 pkcs11_api.h

## 🎯 НАЗНАЧЕНИЕ
Публичный API для работы с PKCS#11 токенами.
Определяет единый интерфейс ITokenModule для всех типов аппаратных токенов.

## 📥 ВХОДНЫЕ ДАННЫЕ (ОТ КОГО)
| Параметр | Откуда | Описание |
|----------|--------|----------|
| library_path | Python биндинги | Путь к PKCS#11 библиотеке |
| slot_id | SessionManager | ID слота с токеном |
| pin | GUI/CLI | PIN-код (4-8 символов) |
| key_id | KeyManager | Идентификатор ключа на токене |
| data | Crypto module | Данные для подписи/шифрования |
| params | KeyManager | Параметры RSA операций |

## 📤 ВЫХОДНЫЕ ДАННЫЕ (КУДА)
| Данные | Куда | Формат |
|--------|------|--------|
| session_id | SessionManager | int32_t, >0 успех |
| key_id | KeyManager | hex строка, 32 символа |
| signature | Crypto module | vector<uint8_t> |
| ciphertext | Crypto module | vector<uint8_t> |
| key_info | KeyManager | KeyInfo структура |
| token_info | GUI/Monitoring | TokenInfo структура |
| result | Вызывающий код | TokenResult enum |

## 🔧 СИСТЕМНЫЕ ЗАВИСИМОСТИ
- НЕТ прямых системных вызовов (pure virtual interface)
- Зависит от: `<cstdint>`, `<string>`, `<vector>`, `<memory>`
- Используется: pybind11 для Python биндингов

## 🧠 ЛОГИКА РАБОТЫ
1. **Абстрактный интерфейс** - все методы pure virtual
2. **Фабрика** - CreateTokenModule(TokenType) создает конкретную реализацию
3. **Детекция** - DetectTokenType() определяет тип по пути к библиотеке
4. **RAII** - виртуальный деструктор обеспечивает правильное удаление

## 🚨 КРИТИЧЕСКИЕ ТРЕБОВАНИЯ
| Требование | Причина | Нарушение |
|------------|---------|-----------|
| ❌ НЕ использовать extern "C" | C++ ABI выбран осознанно | Ломает pybind11 |
| ❌ НЕ экспортировать STL символы | ODR violations | Краш в runtime |
| ✅ Фиксированные размеры типов | ABI стабильность | Размеры зависят от платформы |
| ✅ Zero-initialization | Нет мусора в памяти | Undefined behavior |

## 📝 ПРИМЕР ИСПОЛЬЗОВАНИЯ
```cpp
// Создание модуля
auto module = CreateTokenModule(TokenType::RUTOKEN);
module->Initialize("/usr/lib/librtpkcs11ecp.so");

// Открытие сессии
SessionId sid = module->OpenSession(0, "12345678");

// Генерация ключа
RsaKeyParams params;
params.key_size = 2048;
std::string key_id = module->GenerateRsaKeyPair(sid, params);
```
