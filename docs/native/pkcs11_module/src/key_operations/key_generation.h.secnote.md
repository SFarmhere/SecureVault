# 📁 key_generation.h

## 🎯 НАЗНАЧЕНИЕ  
Заголовочный файл для высокоуровневой генерации ключевых пар на аппаратных токенах.  
- Объявляет структуру `KeyGenerationResult` для возврата результата операции.  
- Предоставляет функции `GenerateRsaKeyPair`, `GenerateRsaKeyPairDefault` и `IsRsaKeyGenerationSupported`.  
- Делегирует низкоуровневую генерацию интерфейсу `ITokenModule::GenerateRsaKeyPair()`.

Приватный ключ **никогда не покидает токен** — генерируется и остаётся на аппаратном уровне.

## 🚨 КРАЙНИЕ СЛУЧАИ

- [x] **Неинициализированный модуль** – `GenerateRsaKeyPair` проверяет `module.IsInitialized()` и возвращает `ERR_NOT_INITIALIZED`.  
- [x] **Недопустимый размер ключа** – если `params.key_size` не 2048 и не 4096, возвращается `ERR_KEY_SIZE`.  
- [x] **Ошибка генерации на токене** – если `module.GenerateRsaKeyPair()` возвращает пустой `key_id`, возвращается `ERR_KEY_TYPE`.  
- [x] **Неинициализированный модуль в IsRsaKeyGenerationSupported** – возвращает `false`.  
- [ ] **Поддержка EC-ключей** – в текущей версии реализована только RSA; EC требует расширения.  
- [ ] **Проверка поддержки механизма на токене** – `IsRsaKeyGenerationSupported` проверяет только размер, а не реальную поддержку механизма на конкретном токене.

## 🧪 ТЕСТЫ (планируемые)

- [ ] Успешная генерация RSA-2048 на токене – проверить `SUCCESS` и непустой `key_id`.  
- [ ] Успешная генерация RSA-4096 на токене.  
- [ ] Генерация с неинициализированным модулем – ожидать `ERR_NOT_INITIALIZED`.  
- [ ] Генерация с недопустимым размером (например, 1024) – ожидать `ERR_KEY_SIZE`.  
- [ ] `IsRsaKeyGenerationSupported` для поддерживаемого и неподдерживаемого размера.  
- [ ] Проверка, что `public_key_pem` заполнен после успешной генерации.
