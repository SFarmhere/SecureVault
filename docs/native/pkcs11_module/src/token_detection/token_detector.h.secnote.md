# 📁 token_detector.h

## 🎯 НАЗНАЧЕНИЕ  
Заголовочный файл для `TokenDetector` — класса обнаружения и идентификации аппаратных токенов по пути к PKCS#11 библиотеке.

- Определяет тип токена (Рутокен, eToken, JaCarta, YubiKey, Smart Card и др.) по имени файла библиотеки.
- Поддерживает кроссплатформенные пути (Windows `.dll`, Linux `.so`, macOS `.dylib`).
- Предоставляет расширенную детекцию с указанием производителя и уверенности.

## 🚨 КРАЙНИЕ СЛУЧАИ

- [x] **Пустой путь** – `Detect` возвращает `TokenType::UNKNOWN`.
- [x] **Несуществующий файл** – `Detect` всё равно определяет тип по имени (без проверки существования).
- [x] **Несоответствующее расширение** – `IsLikelyPkcs11Library` возвращает `false`.
- [x] **Неизвестный токен** – возвращается `TokenType::UNKNOWN` с нулевой уверенностью.
- [ ] **Совпадение по подстроке** – может давать ложные срабатывания (например, "token" в пути).
- [ ] **Кастомные токены** – не поддерживаются без добавления в таблицу детекции.

## 🧪 ТЕСТЫ (планируемые)
