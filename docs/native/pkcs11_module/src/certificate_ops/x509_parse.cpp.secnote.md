# 📁 x509_parse.cpp

## 🎯 НАЗНАЧЕНИЕ  
Реализует базовые функции для работы с X.509 сертификатами:  
- Парсинг DER-представления в структуру `CertificateInfo` (упрощённо, без OpenSSL).  
- Конвертация между PEM и DER форматами.  
- Проверка срока действия сертификата.

В текущей версии парсинг неполный – требуется интеграция OpenSSL для чтения всех полей (subject, issuer, расширения и т.д.).  

---

## 📥 ВХОДНЫЕ ДАННЫЕ

| Функция | Параметр | Тип | Откуда | Описание |
|---------|----------|-----|--------|----------|
| **ParseX509Certificate** | `der_data` | `const std::vector<uint8_t>&` | Адаптеры (smartcard, rutoken) при получении сертификата | Бинарные данные сертификата в формате DER |
| **PemToDer** | `pem_data` | `const std::string&` | Внешний ввод (PEM-файл, пользовательский ввод) | Строка, содержащая PEM-сертификат (с маркерами BEGIN/END) |
| **DerToPem** | `der_data` | `const std::vector<uint8_t>&` | Внутренние операции (например, после генерации ключа) | Бинарные данные сертификата в DER |
| **IsCertificateValid** | `cert` | `const CertificateInfo&` | Любой код, имеющий структуру `CertificateInfo` | Информация о сертификате (поля `not_before_ms`, `not_after_ms`) |
| **IsCertificateValid** | `now_ms` | `int64_t` | Вызывающий код (может передать своё время) | Время в миллисекундах (Unix epoch) для проверки; если `0` – берётся текущее системное время |

## 📤 ВЫХОДНЫЕ ДАННЫЕ

| Функция | Возврат | Тип | Куда | Описание |
|---------|---------|-----|------|----------|
| **ParseX509Certificate** | `info` | `CertificateInfo` | Вызывающий код (SessionManager, KeyManager) | Заполненная структура с идентификатором, меткой, версией и публичным ключом (упрощённо) |
| **PemToDer** | `der` | `std::vector<uint8_t>` | Вызывающий код | DER-представление сертификата (или пустой вектор при ошибке) |
| **DerToPem** | `pem` | `std::string` | Вызывающий код | PEM-строка с маркерами (или пустая строка при ошибке) |
| **IsCertificateValid** | `valid` | `bool` | Вызывающий код | `true` – сертификат действителен на момент `now_ms`; `false` – истёк или ещё не начал действовать |

## 🚨 КРАЙНИЕ СЛУЧАИ

- [x] **Пустой вход** – `ParseX509Certificate` с пустым вектором возвращает пустую структуру; `PemToDer` с пустой строкой возвращает пустой вектор; `DerToPem` с пустым вектором возвращает пустую строку.
- [x] **Некорректный PEM** – если в `PemToDer` отсутствуют маркеры `BEGIN`/`END`, возвращается пустой вектор (без падения).
- [x] **Нулевые временные поля** – `IsCertificateValid` пропускает проверку, если `not_before_ms` или `not_after_ms` равны `0`.
- [ ] **Некорректный Base64 в PEM** – текущая реализация не декодирует Base64, а просто копирует символы, поэтому результат невалиден. Требуется доработка (использовать OpenSSL).
- [ ] **Некорректный DER** – если переданные данные не являются валидным сертификатом, парсинг может дать непредсказуемый результат (нужна проверка с OpenSSL).
- [ ] **Большие сертификаты** – использование `std::vector` и `std::string` безопасно, ограничений по размеру нет (кроме памяти).
