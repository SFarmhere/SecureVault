# 📁 certificate_export.cpp

## 🎯 НАЗНАЧЕНИЕ  
Реализует экспорт X.509 сертификатов с аппаратных токенов через интерфейс `ITokenModule`.  
- Возвращает сертификат в виде бинарных данных (`std::vector<uint8_t>`) для дальнейшей обработки.  
- Сохраняет сертификат в файл (бинарный или текстовый, в зависимости от формата, запрашиваемого у модуля).

## 📤 ВЫХОДНЫЕ ДАННЫЕ

| Функция | Возврат | Тип | Куда | Описание |
|---------|---------|-----|------|----------|
| **ExportCertificate** | `data` | `std::vector<uint8_t>` | Вызывающий код (память) | Бинарные данные сертификата (DER, PEM и т.д.) или пустой вектор при ошибке |
| **ExportCertificateToFile** | `success` | `bool` | Вызывающий код | `true` – файл успешно записан; `false` – ошибка (неудачный экспорт или проблемы с файловой системой) |

## 🚨 КРАЙНИЕ СЛУЧАИ

- [x] **Пустой `cert_id`** – `ExportCertificate` возвращает пустой вектор (без вызова модуля).  
- [x] **Неинициализированный модуль** – `ExportCertificate` проверяет `module.IsInitialized()` и при `false` возвращает пустой вектор.  
- [x] **Модуль вернул пустые данные** – `ExportCertificateToFile` возвращает `false` (не создаёт файл).  
- [x] **Проблемы с открытием файла** – `ExportCertificateToFile` возвращает `false`, если `ofstream` не удалось открыть файл (например, нет прав или путь не существует).  
- [x] **Перезапись файла** – файл перезаписывается (режим `std::ios::binary`) без предупреждения.  
- [ ] **Некорректный `format`** – интерпретация формата полностью ложится на модуль; функция не проверяет его валидность.  
- [ ] **Ошибка записи** – если запись прервана (недостаточно места на диске), `ofstream` может записать частичные данные; метод не проверяет состояние `fail()` после записи (только `is_open`).

## 🧪 ТЕСТЫ (планируемые)

- [ ] Успешный экспорт сертификата с валидным `cert_id` – проверить, что возвращаемый вектор не пуст.  
- [ ] Экспорт с пустым `cert_id` – вектор должен быть пустым.  
- [ ] Экспорт с неинициализированным модулем (например, мок с `IsInitialized()` = `false`) – вектор пуст.  
- [ ] Экспорт в файл с валидными параметрами – проверить, что файл создан и его содержимое совпадает с возвращёнными данными.  
- [ ] Экспорт в файл с некорректным путём (нет прав) – вернуть `false`.  
- [ ] Экспорт в файл, когда модуль возвращает пустые данные – файл не создаётся, возврат `false`.  
- [ ] Экспорт с разными форматами (если модуль поддерживает) – проверить, что данные соответствуют ожидаемому формату.
