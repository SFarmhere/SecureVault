# 📁 certificate_ops.h

## 🎯 НАЗНАЧЕНИЕ  
Заголовочный файл, объединяющий все функции для работы с X.509 сертификатами на аппаратных токенах:  
- **Импорт** сертификатов из памяти или PEM-файла на токен.  
- **Экспорт** сертификатов с токена в память или файл.  
- **Парсинг** X.509 сертификатов из DER-данных (упрощённо).  
- **Конвертация** между PEM и DER форматами.  
- **Проверка** срока действия сертификата.

Реализация разбита на три файла:  
- `certificate_import.cpp` – импорт.  
- `certificate_export.cpp` – экспорт.  
- `x509_parse.cpp` – парсинг, конвертация, проверка срока.

Связан с `ITokenModule`, `SessionManager` и Python‑биндингами.

## 🚨 КРАЙНИЕ СЛУЧАИ (общие)

- [x] **Неинициализированный модуль** – все функции импорта/экспорта проверяют `module.IsInitialized()` и возвращают ошибку (для импорта – `ERR_NOT_INITIALIZED`, для экспорта – пустые данные или `false`).  
- [x] **Пустые входные данные** – для импорта: `cert_data.empty()` → `ERR_NOT_INITIALIZED` (можно улучшить), `pem_path.empty()` → `ERR_NOT_INITIALIZED`; для экспорта: `cert_id.empty()` → пустой вектор.  
- [x] **Ошибки файловой системы** – `ImportCertificateFromFile` и `ExportCertificateToFile` проверяют открытие файла, но не обрабатывают ошибки записи/чтения (например, недостаток места).  
- [x] **Некорректный формат** – `format` передаётся как есть, валидация отсутствует (ответственность модуля).  
- [ ] **Дублирующийся импорт** – поведение зависит от модуля (может перезаписать или вернуть ошибку).  
- [ ] **Некорректный PEM** – `PemToDer` не проверяет правильность Base64 и маркеров (кроме наличия BEGIN/END).  
- [ ] **Пустой результат парсинга** – `ParseX509Certificate` при пустом векторе возвращает пустую структуру (без индикации ошибки).

## 🧪 ТЕСТЫ (планируемые)

- [ ] **ImportCertificate**: успешный импорт, неинициализированный модуль, пустые данные, импорт с `key_id`.  
- [ ] **ImportCertificateFromFile**: успешный импорт из файла, несуществующий файл, пустой файл, файл с некорректным PEM.  
- [ ] **ExportCertificate**: успешный экспорт (DER, PEM), неинициализированный модуль, пустой `cert_id`, несуществующий `cert_id`.  
- [ ] **ExportCertificateToFile**: успешное сохранение, ошибка открытия файла (нет прав), пустые данные от модуля.  
- [ ] **ParseX509Certificate**: валидный DER, пустой DER, битые данные.  
- [ ] **PemToDer**: валидный PEM, PEM без маркеров, пустая строка.  
- [ ] **DerToPem**: валидный DER, пустой DER.  
- [ ] **IsCertificateValid**: действующий, истёкший, ещё не начавший, нулевые временные поля.
