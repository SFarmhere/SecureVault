# 📁 certificate_import.cpp

## 🎯 НАЗНАЧЕНИЕ  
Реализует импорт X.509 сертификатов на аппаратные токены через интерфейс `ITokenModule`.  
- Загрузка сертификата из памяти (вектор байт) на токен.  
- Загрузка сертификата из PEM-файла с последующим импортом на токен.  

Импорт предполагает, что сертификат уже сконвертирован в формат, поддерживаемый модулем (обычно DER), и что на токене есть соответствующая ключевая пара для связывания (по `key_id` или автоматически).

---

## 📥 ВХОДНЫЕ ДАННЫЕ

| Функция | Параметр | Тип | Откуда | Описание |
|---------|----------|-----|--------|----------|
| **ImportCertificate** | `module` | `ITokenModule&` | Вызывающий код (SessionManager, KeyManager) | Ссылка на инициализированный модуль токена |
| | `session_id` | `SessionId` | Вызывающий код (открытая сессия) | Идентификатор сессии, через которую производится импорт |
| | `cert_data` | `const std::vector<uint8_t>&` | Вызывающий код (из памяти) | Бинарные данные сертификата (обычно DER) |
| | `label` | `const std::string&` | Вызывающий код (пользователь или система) | Метка (название) сертификата на токене (CKA_LABEL) |
| | `key_id` | `const std::string&` | Вызывающий код (опционально) | Идентификатор ключа, с которым связывается сертификат (CKA_ID) |
| **ImportCertificateFromFile** | `module` | `ITokenModule&` | Вызывающий код | Ссылка на инициализированный модуль токена |
| | `session_id` | `SessionId` | Вызывающий код | Идентификатор сессии |
| | `pem_path` | `const std::string&` | Вызывающий код (путь к файлу) | Путь к PEM-файлу с сертификатом |
| | `label` | `const std::string&` | Вызывающий код | Метка сертификата на токене |

## 📤 ВЫХОДНЫЕ ДАННЫЕ

| Функция | Возврат | Тип | Куда | Описание |
|---------|---------|-----|------|----------|
| **ImportCertificate** | `result` | `TokenResult` | Вызывающий код | Статус операции: `SUCCESS` или код ошибки (например, `ERR_NOT_INITIALIZED`, `ERR_GENERAL`) |
| **ImportCertificateFromFile** | `result` | `TokenResult` | Вызывающий код | Статус операции: `SUCCESS` или код ошибки (например, `ERR_NOT_INITIALIZED`, `ERR_GENERAL`, `ERR_FILE_NOT_FOUND` – через `ERR_GENERAL`) |

## 🚨 КРАЙНИЕ СЛУЧАИ

- [x] **Неинициализированный модуль** – обе функции проверяют `module.IsInitialized()` и возвращают `ERR_NOT_INITIALIZED`.  
- [x] **Пустые данные (`cert_data.empty()`)** – `ImportCertificate` возвращает `ERR_NOT_INITIALIZED` (не совсем корректно, но так реализовано).  
- [x] **Пустой путь (`pem_path.empty()`)** – `ImportCertificateFromFile` возвращает `ERR_NOT_INITIALIZED`.  
- [x] **Файл не открылся** – `ImportCertificateFromFile` возвращает `ERR_GENERAL` (нет детализации).  
- [x] **Файл прочитан, но данные пустые** – возвращается `ERR_GENERAL`.  
- [ ] **Некорректный PEM-формат** – функция не проверяет, является ли файл действительно PEM-сертификатом; ошибка будет обработана модулем (если модуль умеет).  
- [ ] **Некорректный `key_id`** – если указан несуществующий или несоответствующий ключ, модуль должен вернуть ошибку (например, `ERR_KEY_NOT_FOUND`), но функция не интерпретирует.  
- [ ] **Дублирующийся импорт** – если сертификат с таким же `key_id` или `label` уже существует, поведение зависит от модуля (может вернуть ошибку или перезаписать).  
- [ ] **Большие файлы** – `ImportCertificateFromFile` читает весь файл в память, что может быть проблематично для очень больших файлов (но сертификаты обычно малы).

## 🧪 ТЕСТЫ (планируемые)

- [ ] Успешный импорт сертификата из памяти на токен – проверить `SUCCESS`.  
- [ ] Импорт с неинициализированным модулем – ожидать `ERR_NOT_INITIALIZED`.  
- [ ] Импорт с пустым вектором – ожидать `ERR_NOT_INITIALIZED`.  
- [ ] Успешный импорт из PEM-файла – проверить, что сертификат появился на токене.  
- [ ] Импорт из несуществующего файла – ожидать `ERR_GENERAL`.  
- [ ] Импорт из пустого файла – ожидать `ERR_GENERAL`.  
- [ ] Импорт с некорректным `key_id` (если модуль возвращает ошибку) – проверить обработку.  
- [ ] Импорт с дублирующимся `label` – проверить, что модуль возвращает ошибку (если это запрещено).

## 📌 СТАТУС

| Элемент | Статус | Комментарий |
|---------|--------|-------------|
| Импорт из памяти | 🟢 Готово | Простая обёртка над `module.ImportCertificate` |
| Импорт из PEM-файла | 🟢 Готово | Базовое чтение файла и передача данных модулю |
| Обработка ошибок файловой системы | 🟡 Частично | Проверяется только `is_open`, нет проверки `fail()` после чтения |
| Валидация формата PEM | 🔴 Отсутствует | Функция не проверяет, что файл является корректным PEM-сертификатом |
| Детализация ошибок | 🟡 Частично | Используется `ERR_GENERAL` для всех ошибок, связанных с файлом; нет различения "файл не найден", "нет прав", "пустой файл" и т.д. |

**Общий статус:** 🟢 Стабильно, но может быть улучшена обработка ошибок и валидация формата.
