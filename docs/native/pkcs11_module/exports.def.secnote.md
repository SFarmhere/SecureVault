# 📁 exports.def

## 🎯 НАЗНАЧЕНИЕ  
Файл определений экспорта для Windows DLL.  
- Указывает линкеру, какие символы должны быть доступны из `securevault_pkcs11.dll`.  
- Используется только на Windows при сборке shared-библиотеки.  
- Содержит функции с модификатором `SECUREVAULT_API` (например, `CreateTokenModule`, `DetectTokenType`).

---

## 📥 ВХОДНЫЕ ДАННЫЕ

Нет — это статический файл определений.

---

## 📤 ВЫХОДНЫЕ ДАННЫЕ

| Данные | Тип | Куда | Описание |
|--------|-----|------|----------|
| Экспортируемые символы | `list` | Windows linker | Функции, доступные из DLL |

---

## 🚨 КРАЙНИЕ СЛУЧАИ

- [x] **Только Windows** – файл используется только при сборке DLL на Windows.
- [x] **Linux/macOS** – игнорируется, используется `__attribute__((visibility("default")))`.

---

## 🧪 ТЕСТЫ

- [ ] Проверка, что все `SECUREVAULT_API` функции экспортируются.
- [ ] Проверка, что внутренние символы не экспортируются.

## 🔗 ЗАВИСИМОСТИ
