# 📁 ptrace_detection.cpp

## 🎯 НАЗНАЧЕНИЕ  
Обнаружение отладчиков через системный вызов `ptrace()` (Linux/macOS).  
- Проверяет, не подключен ли текущий процесс к себе как отладчик.  
- Используется в anti-debug защите `security_module`.  
- Детектирует gdb, lldb, strace и другие отладчики.

---

## 📥 ВХОДНЫЕ ДАННЫЕ

| Параметр | Тип | Откуда | Описание |
|----------|-----|--------|----------|
| `pid` | `pid_t` | Caller | PID процесса (по умолч. 0 = текущий) |

---

## 📤 ВЫХОДНЫЕ ДАННЫЕ

| Данные | Тип | Куда | Описание |
|--------|-----|------|----------|
| `detected` | `bool` | Caller | `true` если отладчик обнаружен |
| `error` | `ErrorCode` | Caller | Код ошибки |

---

## 🚨 КРАЙНИЕ СЛУЧАИ

- [x] **ptrace уже подключен** – возвращается `true` (отладчик обнаружен).
- [x] **EPERM** – процесс не имеет прав на ptrace (нормальное поведение без отладчика).
- [x] **ESRCH** – PID не существует.
- [x] **Root privileges** – root может обойти эту проверку.
- [ ] **Другие методы отладки** – не детектируются (hardware breakpoints, etc).

---

## 🧪 ТЕСТЫ (планируемые)

- [ ] Запуск под gdb → detected = true.
- [ ] Запуск без отладчика → detected = false.
- [ ] Запуск под strace → detected = true.
- [ ] Проверка под root.
