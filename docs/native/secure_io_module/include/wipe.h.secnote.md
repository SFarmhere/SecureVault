# 📁 wipe.h

## 🎯 НАЗНАЧЕНИЕ  
Алгоритмы безопасного затирания данных (secure wipe).  
- Реализации методик: Гутманн (35 проходов), DoD 5220.22-M (7 проходов), simple (1 проход).  
- Затирание файлов и блоков на диске.  
- Защита от восстановления данных (forensic tools).  
- Используется в `secure_io_module` для удаления конфиденциальных файлов.

## 🚨 КРАЙНИЕ СЛУЧАИ

- [x] **SSD/NVMe** – wear leveling может игнорировать overwrite, требуется TRIM/secure erase.
- [x] **Файловая система** – journaling (ext3/4, NTFS) может оставить копии в journal.
- [x] **Недостаточно прав** – возвращается `ERR_ACCESS_DENIED`.
- [x] **Файл не существует** – возвращается `ERR_FILE_NOT_FOUND`.
- [ ] **Временные файлы** – удаление при аварийном завершении.
