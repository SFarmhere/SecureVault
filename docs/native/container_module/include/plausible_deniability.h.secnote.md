# 📁 plausible_deniability.h

## 🎯 НАЗНАЧЕНИЕ  
Механизм правдоподобного отрицания (plausible deniability) для контейнеров.  
- Позволяет скрыть существование контейнера внутри внешнего контейнера.  
- Без пароля невозможно доказать, что скрытый контейнер существует.  
- Внешний контейнер выглядит как случайные данные.  
- Используется в формате v2 (`format_v2.h`).

---

## 📥 ВХОДНЫЕ ДАННЫЕ

| Функция | Параметр | Тип | Откуда | Описание |
|---------|----------|-----|--------|----------|
| **create_deniable_container** | `outer_path` | `std::string` | User | Путь к внешнему контейнеру |
| | `inner_path` | `std::string` | User | Путь к внутреннему контейнеру |
| | `outer_password` | `std::string` | User | Пароль внешнего контейнера |
| | `inner_password` | `std::string` | User | Пароль внутреннего контейнера |
| **open_deniable_container** | `container_data` | `ByteSpan` | Container | Данные контейнера |
| | `password` | `std::string` | User | Пароль (внешний или внутренний) |
| **prove_deniability** | `container_data` | `ByteSpan` | Container | Данные контейнера |

## 📤 ВЫХОДНЫЕ ДАННЫЕ

| Функция | Возврат | Тип | Куда | Описание |

## 🚨 КРАЙНИЕ СЛУЧАИ

- [x] **Неверный пароль** – возвращается `WRONG_PASSWORD`, невозможно отличить от несуществующего контейнера.
- [x] **Внешний контейнер** – не содержит магических байт, выглядит как случайные данные.
- [x] **Внутренний контейнер** – скрыт на псевдослучайном смещении.
- [x] **Brute-force защита** – Argon2id KDF для обоих паролей.
- [ ] **Метаданные** – временные метки, размер файла могут泄露 информацию.
