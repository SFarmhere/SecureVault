# 📁 container_api.h

## 🎯 НАЗНАЧЕНИЕ  
Публичный API модуля контейнеров.  
- Создание, открытие, закрытие зашифрованных контейнеров.  
- Поддержка форматов v1 (legacy) и v2 (с скрытыми контейнерами).  
- Дедупликация блоков (CDC), WAL, автоматическая сборка мусора.  
- Монтирование как виртуальные диски.

## 🚨 КРАЙНИЕ СЛУЧАИ

- [x] **Неверный ключ** – `open` возвращает `ERR_WRONG_KEY`.
- [x] **Поврежденный контейнер** – `open` возвращает `ERR_CORRUPTED`.
- [x] **Недостаточно места** – `write` возвращает `ERR_NO_SPACE`.
- [x] **WAL восстановление** – автоматическое после сбоя.
- [x] **Скрытые контейнеры** – только формат v2.
- [ ] **Монтирование** – требует root/администратора.

## 🔗 ЗАВИСИМОСТИ

- **`crypto_module`** – AES-256-GCM, RSA-OAEP.
- **`secure_io_module`** – безопасное затирание.
- **`deduplication/`** – CDC дедупликация.
- **`journal/`** – WAL.
- **`format_v1/`, `format_v2/`** – форматы контейнеров.
