# shamir.py

## НАЗНАЧЕНИЕ
Реализация схемы разделения секрета Шамира (Shamir's Secret Sharing) 3-of-5.
Позволяет разделить мастер-ключ на 5 частей, из которых любые 3 достаточны для восстановления.
Используется для восстановления доступа при потере аппаратного токена.

| Параметр | Тип | Откуда | Описание |
|----------|-----|--------|----------|
| secret | bytes | KeyManager | Мастер-ключ для разделения |
| total | int | User config | Общее количество частей (по умолч. 5) |

| shares | List[Share] | Восстановление | Список частей для восстановления |
| serialized_shares | List[bytes] | Файлы/сеть | Сериализованные части |

## АЛГОРИТМ

### Разделение (split)
1. Для каждого байта секрета создается полином степени K-1 над GF(257)
2. Свободный член полинома = байт секрета
3. Остальные K-1 коэффициентов -- случайные числа
4. Полином вычисляется в N точках (x = 1..N)
5. Каждая часть = набор значений для всех байтов

### Восстановление (join)
1. Интерполяция Лагранжа для восстановления полинома по K точкам
2. Вычисление свободного члена (значение в x=0) = секретный байт
3. Сборка всех байтов в исходный секрет

### Формат сериализации Share
```
[4 байта] HEADER "SVSS"
[1 байт]  VERSION = 1
[1 байт]  INDEX (1..255)
[2 байта] VALUE_LENGTH (big-endian)
[N байт]  VALUE
[4 байта] CHECKSUM (SHA256 первых 4 байт)
```

## ОСОБЕННОСТИ

- Работает над полем GF(257) -- простое число, ближайшее к 256
- Арифметика через расширенный алгоритм Евклида
- Проверка целостности каждой части (SHA256 checksum)
- Сериализация/десериализация в бинарный формат
- Генерация криптостойкого мастер-ключа (os.urandom)
- Функции высокого уровня split_secret() / join_shares()
