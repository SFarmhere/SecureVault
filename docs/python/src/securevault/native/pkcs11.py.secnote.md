# pkcs11.py

## НАЗНАЧЕНИЕ
Python биндинги к C++ PKCS#11 модулю через ctypes.
Обеспечивает Python API для работы с аппаратными токенами (Рутокен, eToken, смарт-карты).

## ВХОДНЫЕ ДАННЫЕ

| Параметр | Тип | Откуда | Описание |
|----------|-----|--------|----------|
| library_path | str | Конструктор / initialize() | Путь к C++ библиотеке |
| slot_id | int | get_available_tokens() | ID слота (0..N-1) |
| pin | str | PIN dialog / CLI | PIN-код пользователя |
| session_id | int | open_session() | ID открытой сессии |
| key_id | str | list_keys() | ID ключа (hex строка) |
| data | bytes | Файл для подписи | Данные для криптооперации |

## ВЫХОДНЫЕ ДАННЫЕ

| Данные | Тип | Куда | Описание |
|--------|-----|------|----------|
| tokens | List[TokenInfo] | GUI/CLI | Список доступных токенов |
| session_id | int | SessionManager | ID сессии (>0 успех) |
| keys | List[KeyInfo] | GUI/CLI | Список ключей на токене |
| signature | bytes | Crypto | RSA-подпись |

## КЛАССЫ

| Класс | Назначение |
|-------|------------|
| PKCS11Module | Основной класс для работы с токенами |
| TokenInfo | Python-обертка для информации о токене |
| KeyInfo | Python-обертка для информации о ключе |
| PKCS11Error | Базовое исключение PKCS#11 |
| PinError | Ошибка PIN-кода |
| SessionError | Ошибка сессии |
| TokenNotFoundError | Токен не найден |

## ФУНКЦИИ ВЫСОКОГО УРОВНЯ

| Функция | Назначение |
|---------|------------|
| detect_token_type() | Определить тип токена по пути библиотеки |
| list_available_tokens() | Быстрое получение списка токенов |

## ОСОБЕННОСТИ

- Загрузка библиотеки через ctypes.CDLL (кроссплатформенно)
- Автоматический поиск библиотеки в системе
- Поддержка контекстного менеджера (with)
- Иерархия исключений для разных типов ошибок
- Соответствие C++ ABI-стабильным типам (IntEnum)
- Логирование через стандартный logging
